## 🚀 Overview

InfraTechs is a modern custom software development and cloud engineering firm founded by **Isha Patharia**. We specialize in:
- Full-Stack SaaS MVP Engineering (React, Next.js, Node.js, TypeScript)
- Multi-Tenant Database Architecture (PostgreSQL with Row-Level Security, Redis caching)
- Stripe Monetization & Automated Subscription Billing Webhooks
- Cloud Scale & DevOps Infrastructure (AWS, Vultr, Docker, CI/CD)
- Workstation Maintenance & Technical System Audits (including Wise Cleaner evaluations)
